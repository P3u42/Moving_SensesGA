About the Project

Moving Senses GA is a Unity project that explores the application of Genetic Algorithms to evolve the movement behavior of Non-Player Characters (NPCs).

Instead of manually programming every movement decision, the project uses an evolutionary approach in which NPCs develop and refine their movement strategies across successive generations.

Each generation represents a new population of agents whose behaviors are evaluated according to their performance in the environment. Through evolutionary processes, the system searches for increasingly effective movement behaviors.

The project explores how evolutionary computation can be applied to autonomous agents in games, providing an experimental approach to NPC behavior and Artificial Intelligence.

Project Overview:

-Project: Moving Senses GA

-Main Concept: Evolutionary NPC Behavior

-Artificial Intelligence Technique: Genetic Algorithms

-Engine: Unity

-Programming Language: C#
