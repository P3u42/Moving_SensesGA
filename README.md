Moving Senses GA | Evolutionary NPC Movement with Genetic Algorithms

An experimental project exploring Genetic Algorithms for NPC movement and behavioral evolution, developed with Unity and C#

About the Project

Moving Senses GA is a Unity project that explores the application of Genetic Algorithms to evolve the movement behavior of Non-Player Characters (NPCs).

Instead of manually programming every movement decision, the project uses an evolutionary approach in which NPCs develop and refine their movement strategies across successive generations.

Each generation represents a new population of agents whose behaviors are evaluated according to their performance in the environment. Through evolutionary processes, the system searches for increasingly effective movement behaviors.

The project explores how evolutionary computation can be applied to autonomous agents in games, providing an experimental approach to NPC behavior and Artificial Intelligence.

Project Overview

Project: Moving Senses GA

Artificial Intelligence Technique: Genetic Algorithms

Genetic Algorithm Approach

The project uses Genetic Algorithms to evolve NPC movement behaviors through successive generations.

The general evolutionary process consists of:

Population Initialization: Create an initial population of NPCs with different behavioral configurations.

Behavior Execution: Allow each NPC to interact with the environment and execute its movement strategy.

Fitness Evaluation: Evaluate each agent's performance according to the project's fitness criteria.

Selection: Select individuals based on their evaluated performance.

Crossover: Combine genetic information from selected individuals to generate new behavioral configurations.

Mutation: Introduce genetic variations to explore alternative movement strategies.

New Generation: Create a new population and repeat the evolutionary process.

Through this iterative process, NPCs can progressively develop movement strategies adapted to the environment and the defined objectives.
